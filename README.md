# Android Portfolio Assessment

This repository contains my **individual portfolio** for Android Development, structured around four units of codelabs.  
Each unit demonstrates my progress in learning Kotlin, Android Studio, UI design, app architecture, and responsive design.  
The portfolio includes achievement badges, Kotlin practice code, reflection notes, and structured documentation.

---

## 📚 Units Overview

### [Unit 1: Your First Android App](./Unit1_Codelabs)
- Duration: 10 hours
- Pathways: Introduction to Kotlin, Setup Android Studio, Build a Basic Layout
- Focus: Writing simple Kotlin programs, setting up Android Studio, building a basic UI with text and images.
- Deliverables: Badge, Kotlin code, Reflection notes.

---

### [Unit 2: Building App UI](./Unit2_Codelabs)
- Duration: 21 hours
- Pathways: Kotlin Fundamentals, Add a Button to an App, Interacting with UI and State
- Focus: Conditionals, classes, lambdas, simulating button clicks, and building a tip calculator logic.
- Deliverables: Badge, Kotlin code (fundamentals, button simulation, tip calculator), Reflection notes.

---

### [Unit 3: Display Lists and Use Material Design](./Unit3_Codelabs)
- Duration: 15 hours
- Pathways: More Kotlin Fundamentals, Build a Scrollable List, Build Beautiful Apps
- Focus: Data classes, collections, scrollable lists, click listeners, Material Design principles (colors, typography, accessibility).
- Deliverables: Badge, Kotlin code (data classes, list simulation, Material Design simulation), Reflection notes.

---

### [Unit 4: Navigation and App Architecture](./Unit4_Codelabs)
- Duration: 28 hours
- Pathways: Architecture Components, Navigation in Jetpack Compose, Adapt for Different Screen Sizes
- Focus: ViewModels, StateFlow, navigation logic, responsive design for phones, tablets, and desktops.
- Deliverables: Badge, Kotlin code (architecture simulation, navigation simulation, responsive UI simulation), Reflection notes.

---

## 📝 Reflection Across All Units
- **Unit 1:** Built confidence in Kotlin basics and Android Studio setup.  
- **Unit 2:** Strengthened fundamentals and practiced interactive logic (buttons, state).  
- **Unit 3:** Learned structured data handling and design principles with Material Design.  
- **Unit 4:** Connected Kotlin logic with modern Android architecture, navigation, and responsive design.

This portfolio demonstrates my journey from **basic Kotlin programming** to **modern Android app architecture**.
