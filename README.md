# Android Portfolio Assessment

This repository contains my **individual portfolio** for Android Development, structured around four units of codelabs.  
Each unit demonstrates my progress in learning Kotlin, Android Studio, UI design, app architecture, and responsive design.  
The portfolio includes achievement badges, Kotlin practice code, reflection notes, and structured documentation.

---

## 📚 Units Overview

### [Unit 1: Your First Android App](./Unit1_Codelabs)
- Duration: 10 hours
- Pathways: Introduction to Kotlin, Setup Android Studio, Build a Basic Layout
- Focus: Writing simple Kotlin programs, setting up Android Studio, building a basic UI with text and images.
- Deliverables: Badge, Kotlin code, Reflection notes.

---

### [Unit 2: Building App UI](./Unit2_Codelabs)
- Duration: 21 hours
- Pathways: Kotlin Fundamentals, Add a Button to an App, Interacting with UI and State
- Focus: Conditionals, classes, lambdas, simulating button clicks, and building a tip calculator logic.
- Deliverables: Badge, Kotlin code (fundamentals, button simulation, tip calculator), Reflection notes.

---

### [Unit 3: Display Lists and Use Material Design](./Unit3_Codelabs)
- Duration: 15 hours
- Pathways: More Kotlin Fundamentals, Build a Scrollable List, Build Beautiful Apps
- Focus: Data classes, collections, scrollable lists, click listeners, Material Design principles (colors, typography, accessibility).
- Deliverables: Badge, Kotlin code (data classes, list simulation, Material Design simulation), Reflection notes.

---

### [Unit 4: Navigation and App Architecture](./Unit4_Codelabs)
- Duration: 28 hours
- Pathways: Architecture Components, Navigation in Jetpack Compose, Adapt for Different Screen Sizes
- Focus: ViewModels, StateFlow, navigation logic, responsive design for phones, tablets, and desktops.
- Deliverables: Badge, Kotlin code (architecture simulation, navigation simulation, responsive UI simulation), Reflection notes.

# Reflection - Android Portfolio Assessment

## What I Learned
- **Unit 1: Your First Android App**
  - How to write simple Kotlin programs that display text output.
  - How to install and configure Android Studio.
  - How to build a basic layout with text and images.
  - How to run an app on an emulator or physical device.

- **Unit 2: Building App UI**
  - Strengthened Kotlin fundamentals: conditionals, classes, lambdas, and function types.
  - Learned how apps respond to user actions such as button clicks.
  - Practiced state management through a tip calculator example.

- **Unit 3: Display Lists and Use Material Design**
  - How to use data classes, functions, and collections in Kotlin.
  - How to simulate scrollable lists and add click listeners.
  - The principles of Material Design: colors, shapes, typography, and accessibility.

- **Unit 4: Navigation and App Architecture**
  - How to explain activities and their lifecycles.
  - Basics of modern Android architecture using ViewModels and StateFlow.
  - How navigation works between multiple screens.
  - Principles of adaptive and responsive design for different screen sizes.

---

## Challenges
- **Unit 1:**  
  - Setting up the Android Studio environment and emulator took time.  
  - Understanding the structure of XML layouts was initially confusing.  

- **Unit 2:**  
  - Lambda expressions and function types required extra practice.  
  - Simulating UI interactions outside Android Studio was limited.  
  - Translating logic into user interface behavior was a new skill.  

- **Unit 3:**  
  - Understanding how lists connect to UI components in Android.  
  - Translating Material Design guidelines into Kotlin-only simulations.  
  - Managing collections and filtering data efficiently.  

- **Unit 4:**  
  - Understanding StateFlow and UDF patterns required careful study.  
  - Simulating navigation outside Android Studio was limited.  
  - Responsive design concepts were new and required practice.
